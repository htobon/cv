CGIAR Level Agricultural Results Interoperable System Architecture (CLARISA)
Interoperability System · Jan 2018 – Present · Alliance of Bioversity International and CIAT
CLARISA is a set of standards that allow CGIAR management information systems to talk to each other, fluidly, exchanging information across different platforms. It enables interoperability across different management information systems (MIS) in CGIAR by providing web-based services with agreed embedded standards. CLARISA provides systems like MARLO, MEL, or OCS access to a defined set of "Control Lists" that contain key sets of information needed for different systems to effectively exchange data. CLARISA was created in 2018 to address known interoperability issues between the different MIS.
  • Ensure that data/information taken from different CGIAR databases and systems are comparable, allowing the System Management Office and other CGIAR Units to run the business more efficiently with consistent stories from the data.
  • Enable two or more systems to communicate and exchange data optimizing resources and operating cost-effectively (e.g. entering data only once for multiple uses), while allowing flexibility to the organizational structure of CGIAR.
  • Accommodate different systems, taking lessons into account that they contain, and be agile to serve different purposes while contributing to a greater common goal.

Arquitectura de Sistema Interoperable de Resultados Agrícolas a Nivel CGIAR (CLARISA)
Sistema de Interoperabilidad · Ene 2018 – Presente · Alianza de Bioversity International y CIAT
CLARISA es un conjunto de estándares que permiten a los sistemas de información de gestión de CGIAR comunicarse entre sí de manera fluida, intercambiando información entre diferentes plataformas. Habilita la interoperabilidad entre distintos sistemas de información de gestión (MIS) en CGIAR al proporcionar servicios web con estándares integrados acordados. CLARISA brinda a sistemas como MARLO, MEL u OCS acceso a un conjunto definido de "Listas de Control" que contienen información clave necesaria para que los diferentes sistemas intercambien datos de manera efectiva. CLARISA fue creada en 2018 para abordar problemas conocidos de interoperabilidad entre los diferentes MIS.
  • Garantizar que los datos/información tomados de diferentes bases de datos y sistemas de CGIAR sean comparables, permitiendo a la Oficina de Gestión del Sistema y otras unidades de CGIAR operar de manera más eficiente con historias consistentes a partir de los datos.
  • Permitir que dos o más sistemas se comuniquen e intercambien datos optimizando recursos y operando de manera costo-efectiva (p. ej. ingresando datos solo una vez para múltiples usos), mientras permiten flexibilidad a la estructura organizacional de CGIAR.
  • Acomodar diferentes sistemas, teniendo en cuenta las lecciones que contienen, y ser ágil para servir diferentes propósitos y contribuir a un objetivo común mayor.
